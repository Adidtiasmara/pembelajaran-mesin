# Pembelajaran Mesin

Repositori ini berisi catatan, praktikum, dan tugas mata kuliah **Pembelajaran Mesin** dengan kode mata kuliah `RTI235004`.

Materi disusun berdasarkan tahapan pengembangan machine learning, mulai dari pemahaman data hingga deployment model.

## Materi

- Pengenalan Artificial Intelligence dan Machine Learning
- Jenis-jenis pembelajaran mesin
- Etika dan tantangan penggunaan AI
- Exploratory Data Analysis
- Pra-pengolahan data
- Imputasi, encoding, normalisasi, dan standardisasi
- Ekstraksi dan seleksi fitur
- Regresi
- Klasifikasi menggunakan kNN, Naive Bayes, dan SVM
- Klasterisasi menggunakan K-Means, DBSCAN, dan HDBSCAN
- Approximate Nearest Neighbors dengan ANNOY, FAISS, dan HNSW
- Artificial Neural Network
- Convolutional Neural Network
- Machine learning pipeline dan deployment

## Dataset

Beberapa dataset yang digunakan dalam materi dan praktikum:

- Titanic Dataset
- Wisconsin Breast Cancer Dataset
- Iris Dataset
- Mall Customers Dataset
- Credit Card Customer Dataset
- SMS Spam Dataset
- Churn Modelling Dataset
- MNIST dan CIFAR Dataset
- Cats versus Dogs Dataset
- Dataset citra siang dan malam
- Dataset musik Spotify
